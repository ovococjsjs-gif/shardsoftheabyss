# Manuscript

## Статус: книга пишется заново с первой главы

Решение от июля 2026. Прежний текст (главы 1–6) перемещён в `90-archive/manuscript-drafts/`.

Причина: числовая калибровка показала системный дефект ритма. Разбор — `02-writing-system/AUDIT-why-old-draft-failed.md`.

## Отношение к старому тексту

| Берём | Не берём |
|---|---|
| События и их последовательность | Стиль и ритм |
| Персонажей и отношения | Объём глав |
| Мир, места, бытовые детали | Формулировки и фразы |
| Хореографию нападения | Структуру глав |

Старый текст — источник справок, а не заготовка для правки.

## Структура

```
arc-01/   главы 1–5 — Минта, обычная жизнь, нападение
```

Внутри арки:
- `PLAN-arc-XX.md` — архитектура арки;
- `BRIEF-chNN.md` — паспорт главы до письма;
- `ch-NN.md` — проза;
- `AUDIT-chNN.md` — разбор после письма.

## Целевые параметры

| Что | Значение |
|---|---|
| Форма | трилогия |
| Книга | ~150 000 слов |
| Глав в книге | ~20 |
| Средняя глава | 7 500 слов, разброс 6 000–10 000 |
| Арка 1 | главы 1–5, ~38 000 слов |

## Порядок работы над главой

1. Паспорт по `02-writing-system/IDEAL-CHAPTER-TEMPLATE.md`
2. Черновик целиком — **без замеров во время письма**
3. `python3 scripts/style_guard.py <файл>`
4. Тройное ревью в `temp/`
5. Правки, фильтры, линейное чтение
6. Повтор, если не держится
