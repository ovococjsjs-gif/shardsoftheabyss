# shardsoftheabyss

Рабочий репозиторий книги **«Хроники Этериума — Осколки Бездны»**.

Тёмное фэнтези с метафизикой личности. POV первой арки — Сильвия, первое лицо.
Ориентир первой книги: 20–24 главы, 150 000–170 000 слов.

---

## Быстрый вход

Перед любой работой над прозой читать по порядку:

1. `00-start-here/SESSION-BRIEF.md`
2. `02-writing-system/PRIMARY-WORK-INSTRUCTION.md`
3. `02-writing-system/HARD-BLOCKERS.md`
4. `02-writing-system/VOICE-SYSTEM.md`
5. `02-writing-system/WORKFLOW-AND-QUALITY-GATE.md`

Перед показом любого нового текста:

```bash
python3 scripts/style_guard.py <файл>
```

`BLOCKER` — текст не готов.

## Структура

```
00-start-here/     короткий вход: бриф и карта проекта
01-canon/          библия, статус, расширение мира
02-writing-system/ голос, процесс, блокеры, шаблон главы
03-manuscript/     рукопись по аркам
  arc-01/          главы 1–5: план, решения, брифы, проза
scripts/           style_guard.py
90-archive/        legacy-документы, дубли, логи сессий
```

---

## Три уровня контекста

Проект не читается целиком перед каждой задачей.

**Уровень 1 — всегда**
`SESSION-BRIEF.md`, `HARD-BLOCKERS.md`, `VOICE-SYSTEM.md`, `WORKFLOW-AND-QUALITY-GATE.md`

**Уровень 2 — по задаче**
`PROJECT-MAP.md`, `STYLE-EXAMPLES.md`, `IDEAL-CHAPTER-TEMPLATE.md`, бриф текущей главы

**Уровень 3 — при глубокой проверке**
`01-canon/*`, соседние главы рукописи, архив

---

## Текущее состояние

**Книга пишется заново с первой главы** (решение от июля 2026).

Прежний текст глав 1–6 перемещён в `90-archive/manuscript-drafts/` и служит источником по событиям, персонажам и миру — но не по стилю, ритму и объёму.

Причина: `02-writing-system/AUDIT-why-old-draft-failed.md`

| Что | Значение |
|---|---|
| Форма | трилогия |
| Книга | ~150 000 слов, ~20 глав |
| Средняя глава | 7 500 слов |
| Арка 1 | главы 1–5, ~38 000 слов |
| Сейчас в работе | глава 1 |

---

## Главный принцип

Работа над главой — это не написание, а рекурсивный цикл доведения.
Написанный текст является сырьём, а не результатом.

Подробно: `02-writing-system/PRIMARY-WORK-INSTRUCTION.md`
