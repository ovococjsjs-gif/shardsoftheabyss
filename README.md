# shardsoftheabyss

Рабочий репозиторий книги **«Хроники Этериума — Осколки Бездны»**, книга первая.

Тёмное фэнтези с метафизикой личности. POV — Сильвия, первое лицо.
Черновик первой книги написан целиком: **35 глав, ~354 000 слов**. Идёт редактура с главы 1.

---

## Где что лежит

```
00-start-here/     старые входные документы (частично устарели, см. ниже)
01-canon/          библия проекта, FACTS.tsv, расширение мира, moral-axis (философская ось автора)
02-writing-system/ скилл, блокеры, голоса, калибровка + AUTHOR-SKILL-external (скилл из внешней сессии автора)
03-manuscript/     рукопись по аркам (arc-01 … arc-05), GUNS.md — реестр ружей
04-review/         ревью книги (REVIEW-BOOK-1, FIX-PLAN), логи редактуры по главам, 00-STATE — текущее состояние
05-publication/    PDF-сборки; author-pdf-2026-09-01/ — авторские PDF глав 1–21 от 01.09 (+ их md-развёртка)
scripts/           build_pdf.py, pdf2md.py, проверки (canon_check, continuity_check, dialog_shape …)
90-archive/        старые черновики, дубли, логи сессий
```

## Какая версия главы актуальна

| Главы | Актуальная версия | Примечание |
|---|---|---|
| 1–3 | `03-manuscript/arc-01/ch-0N.md` | редактура 02–04.09 поверх авторского PDF; ждёт вердикта |
| 4–21 | `03-manuscript/…/ch-NN.md` — база | авторский PDF от 01.09 содержит правки, которых в md нет; переносятся вручную при редактуре главы |
| 22–35 | `03-manuscript/…/ch-NN.md` | единственная версия |

## Порядок редактуры (принят 04.09.2026)

1. Одна глава за раз, по порядку.
2. Медленное чтение по сценам → разбор с нумерованными пунктами → вердикт автора → правки → PDF.
3. Крупные правки показываются вариантом текста, не описанием.
4. Скрипты — пост-проверка (`недел`, канон, факты, стыковки), не руководство к письму.
5. Текущее состояние и решения — `04-review/00-STATE-2026-09-04.md`.

## Сборка PDF

```bash
pip install --break-system-packages fpdf2 pyphen pymupdf
python3 scripts/build_pdf.py 03-manuscript/arc-01/ch-01.md   # → 05-publication/Глава_01.pdf
```

## Что устарело

`00-start-here/*`, `01-canon/PROJECT-STATUS.md` и `03-manuscript/README.md` описывают состояние июля–августа («книга пишется заново», «20 глав», «арка 2 в работе»). Канон в них верный, статус — нет. Правятся по мере работы.
