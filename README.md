# shardsoftheabyss

Рабочий репозиторий романа **«Хроники Этериума — Осколки Бездны»**.

Тёмное фэнтези с метафизикой личности, серой моралью и близким POV Сильвии от первого лица.

## Текущее состояние

- первая книга написана полностью;
- рабочая рукопись: **36 глав**, около 334 000 слов;
- прежняя глава 20 разделена по утверждённой автором границе на новые главы 20–21;
- полное тройное ревью завершено: `04-review/REVIEW-BOOK-1.md`;
- волны 1–4 и финальный редакторский гейт завершены;
- итог: `04-review/FINAL-GATE.md`; оперативный статус: `04-review/EDIT-STATUS.md`.

## Быстрый вход

Перед работой над прозой читать:

1. `00-start-here/SESSION-BRIEF.md`
2. `02-writing-system/SKILL-writing-craft.md`
3. `01-canon/project-bible.md` — нужные разделы канона
4. `02-writing-system/HARD-BLOCKERS.md`
5. `02-writing-system/VOICE-SYSTEM.md`
6. `02-writing-system/WORKFLOW-AND-QUALITY-GATE.md`

Перед показом изменённой главы:

```bash
python3 scripts/style_guard.py <файл>
python3 scripts/knowledge_check.py <файл>
python3 scripts/continuity_check.py <файл>
```

`BLOCKER` требует ручного разбора: истинный дефект исправляется, ложное срабатывание фиксируется в редакторском журнале. Скрипт не заменяет линейного чтения.

## Структура

```text
00-start-here/     актуальный вход и карта проекта
01-canon/          библия, факты и статус канона
02-writing-system/ скилл, голос, блокеры и процесс
03-manuscript/     рукопись по пяти аркам
04-review/         полное ревью, план и журнал редакторского прохода
scripts/           автоматические проверки и DOCX-экспорт
exports/           редакторская и читательская Word-версии
90-archive/        старые версии, исходные документы и логи
```

## Источники истины

При конфликте действует такой порядок:

1. последнее прямое решение автора;
2. `01-canon/project-bible.md`;
3. `01-canon/FACTS.tsv`;
4. `01-canon/PROJECT-STATUS.md`;
5. `02-writing-system/SKILL-writing-craft.md`;
6. остальные методические документы.

Архивные тексты используются только как справка и не являются текущей рукописью.
