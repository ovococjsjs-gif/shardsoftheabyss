# DOCX export specification

## Назначение

Сборка всей первой книги из `03-manuscript/arc-*/ch-*.md` в два Word-документа:

1. **редакторская версия** — A4, широкое поле для комментариев, Times New Roman 12 pt, полуторный интервал;
2. **читательская версия** — A5, Georgia 10,5 pt, компактная книжная полоса.

## Решение по внешним навыкам

Изучены:

- публичная документация DOCX skill в `anthropics/skills`;
- архив Moonshot/Kimi `docx.zip`, находящийся в `main`.

Оба комплекта имеют лицензии, запрещающие копирование и хранение материалов вне соответствующих сервисов. Поэтому их файлы, бинарные библиотеки, шаблоны и текст инструкций **не копируются в репозиторий**.

Экспортёр `scripts/export_docx.js` является самостоятельной реализацией проекта на открытом npm-пакете `docx`. Из внешних навыков взяты только общеизвестные инженерные принципы: OOXML-валидация, обязательный визуальный/структурный контроль, стили Word вместо ручного форматирования, колонтитулы и навигация.

## Требования к содержанию

- 36 глав строго по порядку;
- каждая глава начинается с новой страницы;
- заголовки являются настоящими Word Heading 1 и видны в панели навигации;
- содержание кликабельно;
- `---` превращается в центрированный разделитель `* * *`;
- `*курсив*` сохраняется как курсив, включая реплики Тени;
- `**жирный**` сохраняется как жирный;
- Markdown-маркеры в видимом тексте отсутствуют;
- абзацы прозы не слипаются и не дробятся;
- нумерация страниц начинается с первой главы;
- титульный лист и содержание не имеют номера страницы;
- U+FFFD и placeholder-текст запрещены.

## Редакторская версия

- A4;
- Times New Roman, 12 pt;
- межстрочный интервал 1,5;
- абзац 1,25 см;
- левое поле 3 см, остальные около 2 см;
- верхний колонтитул с названием и пометой версии;
- нижний колонтитул «Страница X из Y».

## Читательская версия

- A5;
- Georgia, 10,5 pt;
- компактный межстрочный интервал;
- абзац 1 см;
- поля 15–18 мм и корешковый запас;
- спокойные коричнево-серые оттенки служебных элементов;
- первая строка после заголовка и разделителя без отступа;
- номер страницы без редакторской подписи.

## Команды

```bash
npm install
npm run export:docx
npm run validate:docx
```

Отдельные варианты:

```bash
npm run export:docx:editorial
npm run export:docx:reader
```

## Проверка

`scripts/validate_docx.py` проверяет:

- целостность ZIP;
- XML всех частей;
- обязательные OOXML-компоненты;
- наличие header/footer;
- точное совпадение всех блоков прозы с Markdown;
- порядок 36 заголовков;
- сохранение курсивных сегментов;
- отсутствие повреждённых символов и Markdown-маркеров.

Файл DOCX не считается готовым, пока обе версии не проходят эту проверку.
