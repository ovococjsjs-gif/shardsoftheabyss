# Scripts

## `style_guard.py` (v2)

Жёсткий автоматический guard художественной прозы.

### Что проверяет

**1. Лексика** — запрещённые конструкции и маркеры
- `не X, а Y` и все варианты, включая тире и разнесение по предложениям;
- мусорный словарь (`костяшки`, `уголки губ`, `нечто`, `в этот момент` и др.);
- псевдотелесная абстракция (`пришла голова`, `вернулся воздух`);
- метатекстовые метафоры.

**2. Ритм** — главная категория, добавлена в v2
- `STACCATO_GLOBAL` — средняя длина предложения наррации и доля коротких;
- `STACCATO_WINDOW` — локальный рубленый участок;
- `NOMINATIVE_CHAIN` — 3+ безглагольных предложения подряд;
- `ANAPHORA_RUN` — 3+ коротких фразы с одинаковым зачином.

**3. Самоповтор**
- `MONOTONE_DIALOGUE_TAG` — однообразная атрибуция диалога;
- `SELF_DUPLICATE` — дословный повтор предложения в файле;
- `--cross` — дословные совпадения между главами.

**4. Форма**
- одиночные слова-абзацы, плотность `будто` / `словно`.

### Нормы

Откалиброваны по `03-manuscript/arc-01/arc-01-v4-combined.md` — тексту, который автор признал живым:

- средняя длина предложения наррации: **7,6 слова**;
- доля предложений ≤4 слов: **20%**.

Тревога с 34%, брак с 42%.

### Запуск

```bash
python3 scripts/style_guard.py 03-manuscript/arc-02/ch-05-draft.md
```

Несколько файлов с проверкой пересечений:

```bash
python3 scripts/style_guard.py 03-manuscript/arc-02/*.md --cross
```

Только сводка:

```bash
python3 scripts/style_guard.py <файл> --quiet
```

### Правило

Если guard находит `BLOCKER`, текст нельзя показывать как готовый.

### Важно

`blockers: 0` означает «нет известных дефектов», а не «текст хорош». Guard — последний технический слой, он не заменяет чтение. Проверка троек и ритма эвристическая: она намеренно строгая и требует ручного подтверждения.
