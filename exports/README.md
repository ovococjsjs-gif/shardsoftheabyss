# Word exports

## Файлы

- `Хроники_Этериума_Осколки_Бездны_редакторская.docx` — A4, Times New Roman 12 pt, интервал 1,5, широкое левое поле; версия для комментариев и точечных правок.
- `Хроники_Этериума_Осколки_Бездны_читательская.docx` — A5, Georgia 10,5 pt; компактная версия для непрерывного чтения.
- `chapters/Глава_01.docx` … `chapters/Глава_36.docx` — главы по отдельности в редакторском формате, чтобы открывать, комментировать и заменять только текущую главу.

Обе полные версии содержат:

- титульный лист;
- кликабельное содержание из 36 глав;
- настоящие Word-заголовки и панель навигации;
- разрывы страниц перед главами;
- колонтитулы и номера страниц;
- сохранённый курсив Тени и жирные выделения;
- центрированные отбивки сцен `* * *`.

## Пересборка

```bash
npm install
npm run export:docx
npm run export:chapters
npm run validate:docx
npm run validate:chapters
```

Источник всегда берётся из `03-manuscript/arc-*/ch-*.md`. Ручные исправления непосредственно внутри DOCX при следующем экспорте не сохранятся; правки текста следует сначала вносить в Markdown.
